tcl for Python usersPython 사용자를 위한 tcl

toolchain-lite: one verb, no Gradle project.

toolchain-lite: 동사 하나, Gradle 프로젝트 없이.

Install a package패키지 설치

uv tool install toolchain-lite    # once 0.1.0 is on PyPI
tcl install pythonx-compose
tcl --version

./gradlew :tcl:run --args="install pythonx-compose"    # from a checkout

tcl install <package> looks for a pyproject.toml in the current directory and its parents. If there is none it runs uv init --bare first; then it adds the package with uv add, through the same pypackpack backend the Gradle plugin uses.

tcl install <package> 는 현재 디렉터리와 그 상위에서 pyproject.toml 을 찾습니다. 없으면 먼저 uv init --bare 를 실행하고, Gradle 플러그인과 같은 pypackpack 백엔드로 uv add 를 해서 패키지를 추가합니다.

Invocation호출Result결과
tcl install pkgexit 0, uv output on stdout종료 코드 0, stdout 에 uv 출력
tclexit 1, Usage: tcl install <package>종료 코드 1, Usage: tcl install <package>
tcl installexit 1, missing argument종료 코드 1, 인자 누락
tcl otherexit 1, unknown command종료 코드 1, 알 수 없는 명령

install is the only command, matching issue #1. tcl needs uv on PATH and network access to PyPI.

명령은 이슈 #1 그대로 install 하나뿐입니다. tcl 은 PATH 의 uv 와 PyPI 네트워크 접근이 필요합니다.
