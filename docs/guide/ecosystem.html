Ecosystem생태계

toolchain is one part of thisisthepy: Python and Kotlin Multiplatform, in one app.

toolchain 은 thisisthepy 의 한 부분입니다. 하나의 앱 안의 Python 과 Kotlin Multiplatform.

toolchain — you are here — 현재 위치

The Gradle plugin and tcl: the vocabulary for building the Python half of an app.

Gradle 플러그인과 tcl: 앱의 Python 절반을 빌드하는 어휘.

pypackpack

The work: Python acquisition, dependency resolution with uv, cross-compilation, bundling.

작업: Python 획득, uv 의존성 해석, 크로스 컴파일, 번들링.

python-multiplatform

The runtime: CPython embedded in Kotlin Multiplatform, and the language boundary.

런타임: Kotlin Multiplatform 에 내장된 CPython 과 언어 경계.

pythonx-compose

Compose Multiplatform, usable from Python.

Python 에서 쓰는 Compose Multiplatform.

torchnative

The real PyTorch ecosystem, on device.

기기 위의 실제 PyTorch 생태계.

Gemstone

An on-device AI chat app built on the stack.

이 스택 위에 만든 온디바이스 AI 채팅 앱.

Where toolchain stopstoolchain 의 경계

If a feature acquires Python, resolves a dependency or builds a bundle, it belongs in pypackpack. If it runs at app start-up, it belongs in python-multiplatform. toolchain's job is the Gradle side in between — and saying clearly when the other side is not there yet.

Python 을 얻거나, 의존성을 해석하거나, 번들을 만드는 기능은 pypackpack 의 것입니다. 앱 시작 시점에 도는 것은 python-multiplatform 의 것입니다. toolchain 의 일은 그 사이의 Gradle 쪽 — 그리고 반대편이 아직 없을 때 그렇다고 분명히 말하는 것입니다.
